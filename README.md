Vira is a Python-based personal AI assistant designed to provide voice-controlled interaction, AI-powered conversations, and desktop automation. The project uses SpeechRecognition for understanding voice commands, pyttsx3 for voice responses, OpenWakeWord for “Hey Vira” wake-word detection, and Ollama with Llama 3.2 for local AI conversations. VIRA can perform various PC automation tasks such as opening applications, searching Google and YouTube, taking screenshots, and providing system information including CPU, RAM, battery, date, and time. The project also includes a decision-making brain, conversation and logging systems, internet-related functionality, and a futuristic PySide6 graphical interface. The main goal of JARVIS is to create a smart, modular, and customizable personal desktop AI assistant that can understand natural voice commands and help users interact with and control their computer more efficiently.
